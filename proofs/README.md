# Preserved proof provenance

These are byte-for-byte historical notes and their linked computational inputs. They document the existing symbolic arguments and provenance; they are not a new mathematical audit. Relative links to project-owned files have been included recursively. Third-party literature is cited, not relicensed.

Historical links to local literature PDFs intentionally remain as provenance and do not resolve in this supplement. Use the live source links and exact reference locations in [CITATION_AUDIT.md](../CITATION_AUDIT.md) instead. The historical notes themselves have not been rewritten.

Use the public `../verify_all.py` command to verify certificates. Historical generator entry points may write output and should not be run inside this frozen supplement. Some historical notes record superseded intermediate research status; the authoritative manuscript and `../CERTIFICATE_INDEX.md` identify the claims used by this release.
